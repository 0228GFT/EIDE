## 项目介绍

本项目是一个基于 **STM32F103RCT6** 微控制器的标准化开发模板，采用模块化设计思想，集成了常用的外设驱动和基础功能模块。通过 VS Code + EIDE 插件实现高效的嵌入式开发体验。

### 主要特性

- ✅ 标准化的项目目录结构
- ✅ 集成 CMSIS 核心库
- ✅ 常用外设驱动（OLED、UART、按键）
- ✅ 模块化设计，易于扩展
- ✅ 支持断点调试和代码格式化
- ✅ 完善的配置文件管理

## 环境依赖

### 必需软件

| 软件/插件 | 版本要求 | 说明 |
|-----------|---------|------|
| VS Code | 最新稳定版 | 代码编辑器 |
| EIDE | 最新稳定版 | 嵌入式 IDE 插件 |
| C/C++ | 最新稳定版 | 语言支持插件 |
| Cortex-Debug | 最新稳定版 | ARM Cortex 调试支持 |

### 硬件要求

- STM32F103RCT6 最小系统板
- ST-Link/J-Link/DAP-Link 调试器
- USB 转串口模块（可选，用于 UART 通信）

### 安装步骤

1. 安装 [VS Code](https://code.visualstudio.com/)
2. 在 VS Code 中安装以下插件：
   - EIDE (Embedded IDE)
   - C/C++
   - Cortex-Debug
3. 克隆或下载本项目到本地
4. 使用 VS Code 打开项目文件夹
5. 连接硬件设备，即可开始开发

## 快速开始

### 编译项目

1. 打开 VS Code，加载项目
2. 按 `Ctrl+Shift+B` 或点击左侧活动栏的 EIDE 图标
3. 选择 "Build" 进行编译
4. 编译成功后，固件位于 `build/Debug/` 目录

### 烧录程序

1. 连接 DAP-Link 调试器到开发板
2. 在 EIDE 界面点击 "Download" 按钮
3. 等待烧录完成

### 调试程序

1. 设置断点
2. 按 `F5` 启动调试
3. 使用调试工具栏控制程序执行

## 模块说明

### 📁 APP (应用层)

存放用户应用程序代码，是项目的主要入口点。

- **main.c/h**: 包含 `main()` 函数，负责系统初始化和主循环逻辑

### 📁 Board (板级支持)

负责开发板的硬件初始化和底层配置。

- **Board.c/h**: 系统时钟配置、GPIO 初始化、外设使能等

### 📁 BSP (板级支持包)

提供具体外设的驱动程序，方便上层应用调用。

### 📁 Libraries (库文件)

存放第三方库和芯片厂商提供的标准库。

- **CMSIS**: ARM 提供的 Cortex-M 系列微控制器软件接口标准

### 📁 Moudle (功能模块)

存放通用的软件模块和中间件。

- **stm32f10x_conf.h**: STM32 外设模块使能配置
- **stm32f10x_it.c/h**: 中断服务函数实现

> 💡 **提示**: 可以在此目录下添加 PID 控制器、FIFO 队列、状态机、软件定时器等通用模块

## 使用说明

### 添加新模块

1. 在 `Project/BSP/` 或 `Project/Moudle/` 下创建新文件夹
2. 编写 [.c]和 [.h]文件
3. 在 EIDE 配置中添加新文件到项目
4. 在需要的地方包含头文件并调用接口

### 代码规范

项目已配置 `.clang-format` 文件，建议：

- 编写代码后使用 `Shift+Alt+F` 格式化代码
- 遵循项目现有的命名规范
- 保持代码风格一致

### 调试技巧

1. **串口打印**: 使用 UART 模块输出调试信息
2. **断点调试**: 在关键位置设置断点，观察变量值
3. **OLED 显示**: 实时显示传感器数据或程序状态

### 常见问题

#### Q: 编译失败怎么办？
A: 
- 检查是否安装了所有必需的 VS Code 插件
- 确认芯片支持包是否正确加载
- 查看编译输出窗口的错误信息

#### Q: 无法烧录程序？
A:
- 检查 DAP-Link 驱动是否安装
- 确认开发板供电正常
- 检查调试器连接线是否牢固

#### Q: 如何修改系统时钟？
A: 在 `Project/Board/Board.c` 中修改时钟配置函数
